# v1.1.0 Roadmap

## Development Goal

v1.1.0 focuses on making the existing Second World feel more alive without changing the v1.0.0 production release, homepage layout, economy rules, or core fishing loop.

The first theme is office life: residents should move through work, breaks, overtime, rest, weekends, weather, festivals, and relationships in a stable and explainable way.

## Office Life Stage

Feature 01: Office Life Schedule 2.0

Status: In development branch `feature/v1.1-office-life-schedule`

Scope:

- Upgrade existing resident schedule resolution.
- Keep existing managers and runtime chain.
- Add schedule phase compatibility for old and sparse JSON.
- Preserve v1.0.0 save compatibility.
- Improve 100-resident fallback state completeness.
