# v1.2.0-rc.1 Release Notes

## 版本亮点

这个候选版本让办公室从静态入口变成可互动的生活场景。玩家可以通过个人中心进入办公室生活视图，看到居民、群体活动、今日办公室状态、职业反馈和世界历史。

## 新增体验

- 查看办公室居民的当前位置、状态和关系。
- 与居民聊天、了解传闻、分享鱼获。
- 看到办公室群体活动、今日事件和世界历史。
- 看到职业、技能、声誉和玩家影响如何反馈到第二世界。

## 主要改善

- 弹窗、覆盖层和指针交互更稳定。
- 本地浏览器验收通过 9 个首页入口和核心钓鱼流程。
- 缺失 JSON 资源不再伪装成 HTML 页面。
- 保存兼容、重复结算保护和资源检查更完整。

## 玩家可执行的新操作

- 进入 Office Hub。
- 查看居民详情。
- 触发居民互动。
- 分享鱼获给居民。
- 查看办公室群体和事件反馈。

## 数据兼容

- 保持 v1.0.0 与 v1.1.0 存档兼容。
- 缺少新字段时使用安全默认值。
- 不要求玩家清空旧存档。

## 已知限制

- 移动端真实浏览器尺寸仍需人工验收。
- 个别鱼类等待对白需要后续编辑去重。
- 测试日志仍偏多。

## 测试范围

- 93 条 Flutter 自动测试。
- 本地 release build。
- 本地 HTTP 关键资源检查。
- 本地浏览器 9 入口点击和核心钓鱼流程。
