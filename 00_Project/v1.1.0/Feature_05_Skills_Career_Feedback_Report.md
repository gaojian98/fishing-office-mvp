# Feature 05 Skills & Career Feedback Report

## Skill Model

- Added `PlayerSkillState` inside `career_state.dart`.
- Supported skills: `fishing`, `communication`, `observation`, `efficiency`, `management`, `luck`.
- New players start with every skill at level 1 and 0 experience.
- Skill level range is `1..10`; skills never downgrade.

## Skill Experience Sources

- Quest/world events can grant skill experience through `QuestRuntimeManager`.
- Resident interactions grant communication and observation through `SecondWorldEngine`.
- Fishing results grant fishing, rare-result luck, and new-fish observation through `FishingProvider`.
- Daily career settlement grants small efficiency/observation growth through `WorldSaveManager`.

## Upgrade Curve

- Level 1 to 2: 100
- Level 2 to 3: 250
- Level 3 to 4: 500
- Level 4 to 5: 900
- Level 5 to 6: 1400
- Level 6 to 7: 2100
- Level 7 to 8: 3000
- Level 8 to 9: 4200
- Level 9 to 10: 6000

Experience overflow is preserved. Large gains can level up more than once. Level 10 keeps recording experience but does not level further.

## Skill Effects And Caps

- `fishing`, `observation`, and `luck` apply a capped fish-result weight bonus.
- Total fish score bonus is capped at `0.06`, preserving rarity ordering.
- `fishing` and `luck` can lightly improve resolved fish weight within the configured range.
- `communication`, `observation`, and `management` can lightly increase positive relationship deltas, capped at `+2`.
- `efficiency` can lightly improve salary calculation, capped at 5%.

## Career Integration

- `CareerState` now includes `skillSummary`, `careerRecommendedSkills`, `promotionSkillRequirements`, and `recentSkillGrowth`.
- Higher promotions can require skills:
  - `team_lead`: communication 3, efficiency 3
  - `manager`: communication 5, management 4
  - `director`: management 7, observation 6
- Missing skill requirements are returned as `skill_<skillId>:<level>`.

## Fishing Integration

- Fish pool selection reads skill levels through `SecondWorldEngine`.
- Skill effects are weight-only and capped.
- Actual fishing skill experience is recorded only when a real fish result is built, not during preview or waiting dialogue lookup.

## Resident Interaction Integration

- `SecondWorldEngine.interactWithResident` records communication/observation growth after real interaction.
- The result includes `skillSummary`, `skillGains`, and `latestCareerFeedback`.
- Skills do not modify resident mood or personality.

## Daily Career Feedback

- Added `CareerFeedback`.
- Generated by `DailySimulationManager` after daily career settlement.
- Stored through `WorldSaveManager.recordCareerFeedback`.
- `DailyWorldSummary` now exposes career feedback, skill gains, level-ups, missing promotion requirements, and recommended actions.
- Feedback text is specific and non-punitive.

## Duplicate Prevention

- Every skill gain requires `sourceType`, `sourceId`, `skillId`, and `amount`.
- Deduplication key: `sourceType::sourceId::skillId`.
- Processed skill sources are saved and capped to the latest 500 entries.
- Career feedback is keyed by date and capped to the latest 30 days.

## Save Compatibility

- `WorldSaveData` adds:
  - `playerSkillStates`
  - `skillExperienceHistory`
  - `processedSkillSourceIds`
  - `careerFeedbackHistory`
  - `latestCareerFeedback`
- Missing old-save fields migrate to default skill states.
- Existing v1.0.0/v1.1 career data is not cleared.

- Skill state is player-only and is not recalculated inside the 100-resident loop.
- Daily feedback is generated only during daily simulation.
- Skill gain history and processed source history are capped.
- No new top-level Manager, Engine, Repository, Runtime, Provider, page, JSON type, or UI was added.

## Known Limits

- No skill JSON/content copy exists yet.
- Future honor/identity/task JSON can reference skill metrics without changing Flutter code.
