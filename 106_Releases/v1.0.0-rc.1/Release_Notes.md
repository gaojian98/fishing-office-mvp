# Fishing Office v1.0.0-rc.1 Release Notes

## Version

v1.0.0-rc.1

## Scope

This release candidate freezes the current playable V1.0 build for founder review and release-readiness validation.

## Included Systems

- Home entry for the standalone Fishing Office game.
- Core fishing loop: start fishing, waiting events, pull line, catch result.
- Fish handling: sell fish or put fish into inventory.
- Wallet, inventory, transaction, task, honor, collection, and profile runtime linkage.
- Second World runtime chain: clock, festival, weather, resident runtime, rumor, fish, economy, relationship, dynamic event, dialogue, story, quest, achievement, and save.
- JSON-driven content packs for residents, fish, dialogue, stories, festivals, weather, rumors, identities, and legends.

## Release Principle

This RC does not add new gameplay. It freezes the current MVP for validation, rollback, and founder acceptance.
