# 05_Content

Content Factory for `上班摸鱼`.

This directory stores content specifications, sample JSON, and schemas.

Do not store Flutter code here.
Do not store UI implementation here.
Do not store final production content until product review is complete.

All content must follow the highest product specification:

- [../00_Project/SecondWorld_Product_Bible.md](../00_Project/SecondWorld_Product_Bible.md)

## Directories

- `Residents/`: resident content templates.
- `Fish/`: fish content templates.
- `Dialogue/`: dialogue content templates.
- `Events/`: event content templates.
- `Festival/`: festival content templates.
- `Legend/`: legend content templates.
- `Office/`: office-world content templates.
- `World/`: second-world content templates.
- `Schemas/`: shared JSON schemas.
